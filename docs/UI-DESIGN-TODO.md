# Omninode UI 디자인 진행표

> 이 문서는 58개 라우트 UI 전환의 진행표다. 기능·API·권한·DB 완료 기준은 루트 `TODO.md`에서 계속 관리한다.

## 운영 규칙

- `[x]`는 대상 라우트 렌더링, fixture 상태, 컴포넌트 테스트와 영향 범위 검증이 끝난 경우에만 표시한다.
- UI 단계에서는 실제 API 호출과 서버 상태 변경을 추가하지 않는다.
- 각 단계는 목록·로딩·빈·오류·권한 없음 상태와 데스크톱/협소 화면 동작을 함께 확인한다.
- UI-0의 공통 컴포넌트와 fixture 계약을 변경하면 영향받는 화면군을 다시 검증한다.
