# 기본 레이아웃 인증 관리자 표시 설계

## 목적

기본 레이아웃 헤더의 우측에 현재 로그인한 관리자의 이메일과 이름을 표시한다. 기존 `/account` 화면의 로그인 결과 표시는 이 요구의 대체 수단으로 확장하지 않는다.

## 범위

- `default` 레이아웃의 헤더 좌측 로고·사이트명 구조는 유지한다.
- 헤더 우측에 인증 관리자 정보를 렌더링하는 공통 컴포넌트를 둔다.
- `auth.store`의 `admin` 상태가 있을 때만 이메일과 이름을 상하로 표시한다.
- 기본 레이아웃을 사용하는 공개 페이지에서도 헤더는 유지하며, 비로그인 상태에서는 관리자 정보만 렌더링하지 않는다.

## 제외 범위

- 역할 표기
- 계정 페이지 이동, 드롭다운, 로그아웃 버튼
- `auth` 레이아웃을 사용하는 `/signin`, `/account/password-change` 화면의 헤더 추가
- 전역 인증 미들웨어의 SSR 오류 및 Nuxt DevTools 경고 수정

## 구성과 데이터 흐름

`app/components/common/`에 헤더 관리자 표시 전용 컴포넌트를 추가한다. 컴포넌트는 `useAuthStore()`만 의존하며, API를 직접 호출하거나 별도 상태를 만들지 않는다.

`app/layouts/default.vue`는 기존 헤더의 우측 영역에 이 컴포넌트를 배치한다. 로그인 성공 또는 세션 복원으로 `auth.store.admin`이 갱신되면 Pinia 반응성에 따라 즉시 표시되며, 로그아웃으로 `admin`이 `null`이 되면 영역도 사라진다.

## UI 규칙

- 이메일은 보조 텍스트, 이름은 주 정보로 둔다.
- 두 값은 우측 정렬된 세로 흐름으로 표시한다.
- 공통 컴포넌트는 CVA와 `cn()` 규칙을 따른다.
- 관리자 정보가 없을 때 빈 컨테이너나 자리표시자를 남기지 않는다.

## 검증

- 컴포넌트 단위 테스트에서 비로그인 상태에는 텍스트가 없고, 로그인 상태에는 이메일과 이름이 보이는지 검증한다.
- 기본 레이아웃이 새 공통 컴포넌트를 렌더링하는지 검증한다.
- 대상 테스트와 lint, 타입 검사, 빌드를 실행한다.
