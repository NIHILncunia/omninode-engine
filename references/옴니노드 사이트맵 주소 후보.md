# 옴니노드 사이트맵 주소 후보

> 현재 단계는 확정 사이트맵이 아니라 브레인스토밍 후보군이다.
> 주소별로 해당 페이지가 사이트맵에서 무엇을 의미하는지 함께 기록한다.

---

# 1. 전역

| 주소 | 의미 |
|---|---|
| `/` | 서비스 진입점 |
| `/projects` | 사용 가능한 프로젝트 전체 목록 |
| `/projects/new` | 새 프로젝트 생성 |
| `/settings` | 옴니노드 자체의 전역 설정 |
| `/about` | 옴니노드 정보 |

---

# 2. 프로젝트 범위

| 주소 | 의미 |
|---|---|
| `/projects/:projectId` | 프로젝트 대시보드. 프로젝트에 속한 모든 월드를 총괄 |
| `/projects/:projectId/worlds` | 프로젝트에 속한 월드 전체 목록 |
| `/projects/:projectId/worlds/new` | 프로젝트에 새 월드 생성 |
| `/projects/:projectId/documents` | 모든 월드의 문서를 통합해서 조회 |
| `/projects/:projectId/categories` | 모든 월드의 카테고리를 통합해서 조회 |
| `/projects/:projectId/templates` | 모든 월드의 템플릿을 통합해서 조회 |
| `/projects/:projectId/relations` | 프로젝트 전체 월드의 관계를 통합해서 조회 |
| `/projects/:projectId/timeline` | 프로젝트 전체 월드를 포괄하는 사건 연표 |
| `/projects/:projectId/search` | 프로젝트 전체 통합 검색 |
| `/projects/:projectId/recent` | 프로젝트 전체의 최근 변경/열람 문서 |
| `/projects/:projectId/favorites` | 프로젝트 범위 즐겨찾기 |
| `/projects/:projectId/activity` | 프로젝트 전체 변경 활동 기록 |
| `/projects/:projectId/trash` | 프로젝트 전체 삭제 항목 |
| `/projects/:projectId/settings` | 프로젝트 자체 설정 |

| `/projects/:projectId/worlds/:worldId/relations` | 월드에 존재하는 관계 전체를 보는 관계도 |

| `/projects/:projectId/worlds/:worldId/timeline` | 월드 전체 사건을 대상으로 한 연표 |

| `/projects/:projectId/worlds/:worldId/activity` | 해당 월드에서 발생한 변경 활동 |
| `/projects/:projectId/worlds/:worldId/trash` | 해당 월드의 삭제 항목 |
| `/projects/:projectId/worlds/:worldId/settings` | 월드 자체 설정 |

# 4. 카테고리

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/categories/new` | 새 카테고리 생성 |
| `/projects/:projectId/worlds/:worldId/categories/:categoryId` | 특정 카테고리 상세/관리 |
| `/projects/:projectId/worlds/:worldId/categories/:categoryId/documents` | 해당 카테고리에 속한 문서 |
| `/projects/:projectId/worlds/:worldId/categories/:categoryId/templates` | 해당 카테고리에 매핑된 템플릿 |
| `/projects/:projectId/worlds/:worldId/categories/:categoryId/relations` | 해당 카테고리의 문서들을 대상으로 한 관계 조회 |

---

# 5. 템플릿

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/templates/new` | 새 기본 템플릿 생성 |
| `/projects/:projectId/worlds/:worldId/templates/:templateId` | 특정 템플릿 상세 |
| `/projects/:projectId/worlds/:worldId/templates/:templateId/edit` | 템플릿 구조 편집 |
| `/projects/:projectId/worlds/:worldId/templates/:templateId/categories` | 해당 템플릿을 사용하는 카테고리 |
| `/projects/:projectId/worlds/:worldId/templates/:templateId/documents` | 해당 템플릿으로 작성된 문서 |

템플릿은 카테고리에 종속된 자원이 아니라 월드 안에서 독립적으로 생성되는 자원이다.

하나의 기본 템플릿을 여러 카테고리에 매핑하여 사용할 수 있다.

# 6. 관계 타입

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/relation-types/new` | 새로운 관계 타입 정의 |
| `/projects/:projectId/worlds/:worldId/relation-types/:relationTypeId` | 관계 타입 상세 |
| `/projects/:projectId/worlds/:worldId/relation-types/:relationTypeId/edit` | 관계 타입 수정 |

관계 타입은 `부모`, `자녀`, `소속`, `소유`, `원인`, `결과`처럼 문서와 문서 사이의 관계가 어떤 의미를 가지는지 정의한다.

# 8. 문서 기준 관계 표현

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/documents/:documentId/relations` | 해당 문서를 중심으로 연결된 관계 전체 표현 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/family-tree` | 해당 인물을 기준으로 관계 데이터에서 자동 구성한 가계도 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/timeline` | 해당 사건을 기준으로 관련 사건들을 연결한 연표 |

`family-tree`와 `timeline`은 별도로 생성하는 자원이 아니다.

기존 설정 문서와 문서 관계를 기준으로 자동으로 도출하여 보여주는 표현 페이지이다.

문서의 종류에 따라 제공되는 관계 표현 페이지가 달라질 수 있다.

예:

- 인물 문서 → 관계도, 가계도
- 사건 문서 → 관계도, 연표
- 사물 문서 → 관계도
- 영지 문서 → 관계도
- 국가 문서 → 관계도

---

# 9. 프로젝트 및 월드 관계 표현

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/relations` | 프로젝트에 포함된 모든 월드의 관계를 포괄적으로 조회 |
| `/projects/:projectId/timeline` | 프로젝트에 포함된 모든 월드의 사건을 포괄하는 연표 |
| `/projects/:projectId/worlds/:worldId/relations` | 특정 월드의 모든 관계 데이터를 대상으로 하는 관계도 |
| `/projects/:projectId/worlds/:worldId/timeline` | 특정 월드의 모든 사건을 대상으로 하는 전체 연표 |

월드 관계도는 인간관계, 사건관계, 사물관계, 영지관계 등 월드에 존재하는 다양한 관계를 포괄할 수 있다.

모든 관계를 반드시 동시에 표시하는 범용 그래프를 강제하는 것이 아니라, 전체 관계 데이터를 탐색할 수 있는 상위 관계 표현 페이지라는 의미이다.

# 10. 위키 엔진 — 리비전

> 1차 개발 범위에서는 제외하고 후속 위키 엔진 단계에서 추가하는 후보이다.

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/documents/:documentId/history` | 해당 문서의 전체 리비전 이력 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/history/:revisionId` | 특정 시점의 문서 리비전 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/compare` | 문서의 두 리비전 간 변경 내용 비교 |

---

# 11. 위키 엔진 — 토론

> 1차 개발 범위에서는 제외하고 후속 위키 엔진 단계에서 추가하는 후보이다.

| 주소 | 의미 |
|---|---|
| `/projects/:projectId/worlds/:worldId/documents/:documentId/discussions` | 해당 문서에 관한 토론 전체 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/discussions/new` | 새 문서 토론 생성 |
| `/projects/:projectId/worlds/:worldId/documents/:documentId/discussions/:discussionId` | 특정 토론 주제 |

# 13. 현재 상태

이 문서는 사이트맵 설계를 위한 브레인스토밍 후보군이다.

향후 각 주소를 다음과 같은 기준으로 검토하여 최종 사이트맵을 확정한다.

- 1차 필수
- 후속 기능
- 위키 엔진 단계
- 보류
- 삭제
