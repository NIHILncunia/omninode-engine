# 월드 대시보드 메뉴 설계

## 1. 목적

월드 대시보드는 선택한 월드와 그 아래 모든 프로젝트를 관리하는 공간이다.

월드 소유 데이터는 직접 관리하고, 프로젝트 소유 데이터는 프로젝트명을 명시한 통합 목록으로 조회한다. 프로젝트 내부의 세부 관리는 프로젝트 대시보드에서 수행한다.

## 2. 관리 경계

| 데이터 | 실제 소관 | 월드 대시보드 | 프로젝트 대시보드 |
|---|---|---|---|
| 월드 정보 | 월드 | 직접 관리 | 해당 없음 |
| 프로젝트 | 월드 | 직접 관리 | 자신의 프로젝트 정보 관리 |
| 관계 유형 | 월드 | 직접 관리 | 조회·사용 |
| 관계 | 월드 | 직접 관리 | 관련 관계 조회·사용 |
| 카테고리 | 프로젝트 | 통합 목록 조회 | 직접 관리 |
| 템플릿 | 프로젝트 | 통합 목록 조회 | 직접 관리 |
| 문서 | 프로젝트 | 통합 목록 조회 | 직접 관리 |
| 어드민 | 월드·프로젝트 권한 | 월드 범위 관리 | 프로젝트 권한 관리 |

## 3. 기본 경로

월드 대시보드의 기본 경로는 `/worlds/:worldId`로 한다.

## 4. 좌측 메뉴

```text
월드
├─ 대시보드
├─ 월드 정보
└─ 프로젝트

월드 데이터
├─ 관계 유형
└─ 관계

프로젝트 데이터
├─ 카테고리
├─ 템플릿
└─ 문서

관리자
└─ 어드민
```

## 5. 메뉴와 콘텐츠 매핑

| 메뉴 그룹 | 좌측 메뉴 | 경로 | 관리 수준 |
|---|---|---|---|
| 월드 | 대시보드 | `/worlds/:worldId` | 월드 전체 현황 조회 |
| 월드 | 월드 정보 | `/worlds/:worldId/settings` | 월드 정보 수정·상태 관리 |
| 월드 | 프로젝트 | `/worlds/:worldId/projects` | 프로젝트 생성·수정·삭제·복원 |
| 월드 데이터 | 관계 유형 | `/worlds/:worldId/relation-types` | 사용자 정의 관계 유형 직접 관리 |
| 월드 데이터 | 관계 | `/worlds/:worldId/relations` | 실제 문서 관계 직접 관리 |
| 프로젝트 데이터 | 카테고리 | `/worlds/:worldId/categories` | 프로젝트별 카테고리 통합 조회 |
| 프로젝트 데이터 | 템플릿 | `/worlds/:worldId/templates` | 프로젝트별 템플릿 통합 조회 |
| 프로젝트 데이터 | 문서 | `/worlds/:worldId/documents` | 프로젝트별 문서 통합 조회 |
| 관리자 | 어드민 | `/worlds/:worldId/admins` | 월드 관리자와 프로젝트 권한 관리 |

## 6. 대시보드

### 6.1 월드 요약

| 카드 | 내용 |
|---|---|
| 프로젝트 | 전체·사용·삭제 프로젝트 수 |
| 카테고리 | 월드 내 모든 프로젝트의 카테고리 수 |
| 템플릿 | 월드 내 모든 프로젝트의 템플릿 수 |
| 문서 | 월드 내 모든 프로젝트의 문서 수 |
| 관계 유형 | 기본·사용자 정의 관계 유형 수 |
| 관계 | 실제 생성된 관계 수 |
| 어드민 | 월드를 관리할 수 있는 관리자 수 |

### 6.2 프로젝트 현황

| 컬럼 | 내용 |
|---|---|
| 프로젝트명 | 프로젝트 이름 |
| 카테고리 수 | 사용 중인 카테고리 수 |
| 템플릿 수 | 사용 중인 템플릿 수 |
| 문서 수 | 등록된 문서 수 |
| 관리자 수 | 관리 권한이 있는 관리자 수 |
| 상태 | 사용·미사용·삭제 |
| 수정일 | 마지막 수정 날짜 |

프로젝트를 선택하면 프로젝트 대시보드로 이동한다.

### 6.3 최근 데이터

- 최근 생성된 프로젝트
- 최근 생성·수정된 문서
- 최근 생성된 관계
- 최근 생성된 사용자 정의 관계 유형
- 최근 추가된 어드민

최근 데이터에는 프로젝트명을 함께 표시한다. 월드 소관인 관계 유형에는 프로젝트명을 표시하지 않는다.

## 7. 월드 정보

| 항목 | 처리 |
|---|---|
| 월드명 | 수정 가능 |
| 월드 설명 | 수정 가능 |
| 사용 상태 | 권한에 따라 변경 |
| 생성자 | 조회만 가능 |
| 생성일 | 조회만 가능 |
| 수정자 | 조회만 가능 |
| 수정일 | 조회만 가능 |
| 삭제 상태 | 조회 및 복원 가능 |

### 7.1 주요 기능

- 월드 이름·설명 수정
- 월드 사용·미사용 전환
- 월드 삭제
- 삭제된 월드 복원

슈퍼 어드민은 항상 작업할 수 있다. 일반·서브 어드민은 부여된 월드 수정·삭제 권한에 따라 버튼을 노출한다.

## 8. 프로젝트

### 8.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 프로젝트명 | 프로젝트 이름 |
| 설명 | 프로젝트 설명 |
| 카테고리 수 | 연결된 카테고리 수 |
| 템플릿 수 | 연결된 템플릿 수 |
| 문서 수 | 등록된 문서 수 |
| 관리자 수 | 관리 권한이 있는 관리자 수 |
| 생성자 | 프로젝트 생성 관리자 |
| 상태 | 사용·미사용·삭제 |
| 생성일·수정일 | 관리 날짜 |

### 8.2 주요 기능

- 프로젝트 생성
- 프로젝트 상세 조회
- 프로젝트 정보 수정
- 사용·미사용 전환
- 프로젝트 삭제·복원
- 프로젝트 대시보드 이동
- 프로젝트 관리자 확인

프로젝트 생성 시 현재 월드는 자동으로 지정하며 다른 월드를 선택하지 않는다.

## 9. 관계 유형

월드에 적용되는 기본 관계 유형과 사용자 정의 관계 유형을 함께 표시한다.

### 9.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 관계 유형명 | 표시 이름 |
| 구분 | 기본 또는 사용자 정의 |
| 방향성 | 단방향 또는 양방향 |
| 역관계 | 반대 관계 유형 |
| 최소 대상 수 | 필요한 최소 문서 수 |
| 최대 대상 수 | 허용되는 최대 문서 수 |
| 사용 관계 수 | 해당 유형으로 생성된 관계 수 |
| 상태 | 사용·미사용·삭제 |

### 9.2 기본 관계 유형

- 시스템 기본 정의 조회
- 월드 적용·해제
- 월드 내 사용·미사용 전환
- 실제 사용 현황 조회
- 기본 정의 자체는 수정·삭제 불가

### 9.3 사용자 정의 관계 유형

- 생성
- 상세 조회
- 수정
- 삭제·복원
- 방향성과 역관계 관리
- 대상 수와 연결 조건 관리
- 사용·미사용 전환

## 10. 관계

월드에 속한 서로 다른 프로젝트의 문서를 연결할 수 있다.

### 10.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 관계 유형 | 적용된 관계 유형 |
| 기준 문서 | 관계의 기준 문서 |
| 기준 프로젝트 | 기준 문서의 프로젝트 |
| 대상 문서 | 연결된 대상 문서 |
| 대상 프로젝트 | 대상 문서가 속한 프로젝트 |
| 대상 수 | 관계 참여 문서 수 |
| 생성자 | 관계 생성 관리자 |
| 상태 | 사용·미사용·삭제 |
| 생성일·수정일 | 관리 날짜 |

다항 관계의 대상 문서가 여러 개라면 각 문서명 옆에 프로젝트명을 함께 표시한다.

### 10.2 주요 기능

- 관계 생성
- 관계 상세 조회
- 관계 수정
- 관계 삭제·복원
- 관계 유형 선택
- 프로젝트별 문서 검색
- 기준 문서와 대상 문서 선택
- 관계 참여 문서의 프로젝트 확인

## 11. 카테고리

월드에 속한 모든 프로젝트의 카테고리를 하나의 목록으로 보여준다.

### 11.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 카테고리명 | 카테고리 이름 |
| 프로젝트 | 카테고리를 사용하는 프로젝트 |
| 구분 | 기본 또는 사용자 정의 |
| 상위 카테고리 | 계층상 상위 항목 |
| 단계 | 1·2·3단계 |
| 템플릿 수 | 연결된 템플릿 수 |
| 문서 수 | 소속 문서 수 |
| 상태 | 사용·미사용·삭제 |

### 11.2 제공 기능

- 프로젝트별 필터
- 기본·사용자 정의 필터
- 단계별 필터
- 이름 검색
- 상세 정보 조회
- 소속 프로젝트 대시보드 이동
- 프로젝트의 카테고리 관리 화면 이동

월드 대시보드에서는 카테고리를 생성·수정·삭제하지 않는다.

### 12.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 템플릿명 | 템플릿 이름 |
| 프로젝트 | 템플릿을 사용하는 프로젝트 |
| 카테고리 | 연결된 카테고리 |

| 문서 수 | 사용하는 문서 수 |
| 상태 | 사용·미사용·삭제 |

### 12.2 제공 기능

- 프로젝트별 필터

- 기본·사용자 정의 필터
- 템플릿명 검색
- 필드 구성 조회
- 적용 현황 조회
- 프로젝트의 템플릿 관리 화면 이동

월드 대시보드에서는 템플릿을 생성·수정·삭제하지 않는다.

### 13.1 목록 항목

|---|---|
| 문서 제목 | 문서 제목 |

| 템플릿 | 적용 템플릿 |
| 관계 수 | 연결된 관계 수 |
| 생성자 | 문서 생성 관리자 |
| 상태 | 사용·미사용·삭제 |

### 13.2 제공 기능

- 프로젝트별 필터

- 연결된 관계 조회
- 프로젝트의 문서 관리 화면 이동

문서 상세는 공용 문서 상세 레이아웃으로 표시한다. 생성·수정·삭제는 프로젝트 대시보드 또는 문서 편집 레이아웃에서 수행한다.

## 14. 어드민

현재 월드에 접근하거나 관리 권한을 가진 관리자만 표시한다.

### 14.1 목록 항목

| 컬럼 | 내용 |
|---|---|
| 이름 | 관리자 이름 |
| 이메일 | 관리자 이메일 |
| 역할 | 일반 어드민 또는 서브 어드민 |
| 관리 프로젝트 | 권한을 가진 프로젝트 |
| 권한 수 | 부여된 세부 권한 수 |
| 계정 상태 | 사용·정지·삭제 |
| 초대 상태 | 발송·수락·만료 |
| 마지막 로그인 | 마지막 로그인 날짜 |

### 14.2 주요 기능

- 월드 관리자 조회
- 서브 어드민 생성·초대
- 초대 재발송
- 월드 접근 권한 설정
- 프로젝트별 관리 권한 설정
- 권한 수정·회수
- 월드에서 관리자 제외

관리자 계정 자체의 전역 역할이나 계정 상태는 옴니노드 대시보드에서 관리한다. 월드 대시보드에서는 현재 월드에 대한 접근과 권한만 관리한다.

## 15. 권한 적용

- 메뉴 접근 권한이 없으면 좌측 메뉴를 숨긴다.
- 조회 권한만 있으면 생성·수정·삭제 버튼을 숨긴다.
- 생성 권한이 있으면 생성 버튼을 노출한다.
- 수정 권한이 있으면 수정·상태 변경 버튼을 노출한다.
- 삭제 권한이 있으면 삭제·복원 버튼을 노출한다.
- 슈퍼 어드민은 모든 메뉴와 작업에 접근할 수 있다.
