# 문서 목록 레이아웃 설계

## 1. 목적

문서 목록 레이아웃은 옴니노드에 존재하는 모든 월드와 프로젝트의 문서를 탐색하는 공용 화면이다.

문서 관리는 프로젝트 대시보드의 문서 메뉴에서 수행한다. 문서 목록 레이아웃은 관리용 데이터 테이블이 아니라 일반 뷰어와 관리자가 함께 사용하는 탐색 화면이다.

## 2. 기본 경로

| 경로 | 처리 |
|---|---|
| `/` | `/docs`로 리다이렉트 |
| `/docs` | 모든 월드·프로젝트의 문서 탐색 |
| `/worlds/:worldId/projects/:projectId/documents` | 프로젝트 레이아웃을 사용하는 문서 관리 |

별도의 `/manage/documents` 경로는 만들지 않는다.

## 3. 레이아웃 경계

| 기능 | 경로 | Vue 레이아웃 |
|---|---|---|
| 전체 문서 탐색 | `/docs` | 문서 목록 레이아웃 |
| 프로젝트 문서 관리 | `/worlds/:worldId/projects/:projectId/documents` | 프로젝트 레이아웃 |
| 문서 생성 | 별도 확정 | 문서 생성·수정 레이아웃 |
| 문서 상세 | 별도 확정 | 문서 상세 레이아웃 |
| 문서 수정 | 별도 확정 | 문서 생성·수정 레이아웃 |

## 4. 공통 구조

```text
상단 헤더
├─ 옴니노드 로고
├─ 문서 검색
└─ 사용자 메뉴

본문
├─ 좌측 탐색
│  ├─ 월드
│  ├─ 프로젝트
│  └─ 카테고리 트리
└─ 문서 목록
   ├─ 현재 탐색 범위
   ├─ 새 문서 작성
   ├─ 필터·정렬
   ├─ 문서 목록
   └─ 페이지네이션
```

## 5. 상단 헤더

| 영역 | 내용 |
|---|---|
| 로고 | `/docs`로 이동 |
| 문서 검색 | 모든 문서 또는 현재 선택 범위 검색 |
| 사용자 메뉴 | 내 대시보드, 접근 가능한 관리 화면, 로그아웃 |
| 로그인 | 비로그인 사용자에게 로그인 버튼 표시 |

## 6. 화면 제목과 요약

```text
모든 문서
모든 월드와 프로젝트에 등록된 설정 문서를 탐색합니다.
```

다음 정보를 간단히 표시한다.

- 전체 월드 수
- 전체 프로젝트 수
- 전체 공개·사용 문서 수
- 현재 검색 조건의 문서 수

관리 통계가 아니라 현재 탐색 범위를 이해하기 위한 정보로 사용한다.

## 7. 좌측 탐색

카테고리는 프로젝트 소관이며 프로젝트마다 구조가 다르다. 따라서 월드와 프로젝트를 먼저 선택한 뒤 해당 프로젝트의 카테고리 트리를 표시한다.

```text
모든 문서

월드
├─ 월드 1
│  ├─ 프로젝트 1
│  └─ 프로젝트 2
└─ 월드 2
   └─ 프로젝트 3

선택한 프로젝트의 카테고리
├─ 인물
├─ 지역
└─ 사건
```

### 7.1 선택 상태

| 선택 범위 | 좌측 탐색 처리 |
|---|---|
| 아무것도 선택하지 않음 | 모든 문서 표시, 카테고리 트리 미표시 |
| 월드만 선택 | 해당 월드의 프로젝트 목록 표시 |
| 프로젝트 선택 | 해당 프로젝트의 카테고리 트리 표시 |
| 카테고리 선택 | 해당 카테고리 문서만 표시 |

서로 다른 프로젝트의 카테고리는 이름이 같더라도 하나로 합치지 않는다.

### 7.2 카테고리 트리 기능

- 1·2·3단계 카테고리 탐색
- 카테고리별 문서 수 표시
- 현재 선택 카테고리 강조
- 카테고리 접기·펼치기
- 모바일에서 드로어로 전환
- 사용 중이고 삭제되지 않은 카테고리만 노출

## 8. 필터 상태와 URL

월드·프로젝트·카테고리 선택은 별도 관리 화면으로 이동하지 않고 `/docs`의 필터 상태로 처리한다.

```text
/docs?worldId=:worldId
/docs?worldId=:worldId&projectId=:projectId
/docs?worldId=:worldId&projectId=:projectId&categoryId=:categoryId
```

### 8.1 필터 종속 관계

```text
월드 선택
└─ 프로젝트 선택
   └─ 카테고리 선택
      └─ 템플릿 선택
```

상위 선택을 변경하면 더 이상 유효하지 않은 하위 필터를 초기화한다.

## 9. 검색·필터·정렬

| 기능 | 내용 |
|---|---|
| 월드 | 전체 또는 특정 월드 |
| 프로젝트 | 선택한 월드의 프로젝트 |
| 카테고리 | 선택한 프로젝트의 카테고리 |
| 템플릿 | 선택한 프로젝트에서 사용하는 템플릿 |
| 검색 | 문서 제목과 검색 가능한 본문 |
| 정렬 | 제목·생성일·수정일 |
| 정렬 방향 | 오름차순·내림차순 |

기본 정렬은 최근 수정순으로 한다.

관리용 상태 필터와 삭제 필터는 제공하지 않는다. 사용 중이고 삭제되지 않은 문서만 표시한다.

## 10. 문서 목록

전역 문서 목록에는 소속 범위를 반드시 표시한다.

| 표시 항목 | 내용 |
|---|---|
| 문서 제목 | 문서 상세 이동 |
| 월드 | 문서가 속한 월드 |
| 프로젝트 | 문서가 속한 프로젝트 |
| 카테고리 | 프로젝트 내 카테고리 경로 |
| 템플릿 | 적용된 템플릿 |
| 요약 | 문서 본문 또는 설명 일부 |
| 관련 문서 수 | 연결된 문서 수 |
| 수정일 | 마지막 수정 날짜 |

```text
아미유
룩스테라 · 인물 설정
인물 > 주요 인물 · 인물 기본 템플릿

청연 출신의 인물로 현재 특정 세력에 소속되어 있다.

관련 문서 8개 · 2026-08-20 수정
```

월드와 프로젝트 정보를 제목 바로 아래에 고정적으로 표시한다.

## 11. 새 문서 작성

### 11.1 노출 조건

- 로그인한 관리자
- 계정이 사용 상태
- 최초 비밀번호 변경 완료
- 문서 생성 권한을 가진 프로젝트가 하나 이상 존재
- 대상 월드와 프로젝트가 사용 상태

슈퍼 어드민에게는 항상 표시하며 모든 사용 중인 프로젝트를 선택할 수 있다.

### 11.2 작성 대상 선택

`/docs`에서 새 문서 작성 버튼을 선택하면 작성 권한이 있는 범위만 보여준다.

```text
새 문서 작성
├─ 권한이 있는 월드 선택
└─ 권한이 있는 프로젝트 선택
   └─ 문서 생성 레이아웃 이동
```

월드와 프로젝트가 필터로 이미 선택되어 있고 해당 프로젝트에 문서 생성 권한이 있다면 선택 단계를 생략할 수 있다.

## 12. 비로그인·권한 없는 사용자

다음 기능만 사용한다.

- 모든 문서 조회
- 월드·프로젝트 탐색
- 카테고리 탐색
- 검색과 필터
- 문서 상세 열기
- 연결 문서 탐색

새 문서 작성 버튼은 표시하지 않는다.

## 13. 목록 상태

| 상태 | 표시 |
|---|---|
| 로딩 | 문서 목록 스켈레톤 |
| 결과 없음 | 조건에 맞는 문서가 없음 |
| 검색 결과 없음 | 검색어와 필터 초기화 안내 |
| 카테고리 문서 없음 | 작성 권한이 있으면 새 문서 작성 버튼 제공 |
| 접근 불가 | 프로젝트 접근 권한 또는 공개 상태 안내 |
| 오류 | 재시도 버튼과 오류 안내 |

## 14. 프로젝트 문서 관리

프로젝트 레이아웃의 기존 메뉴와 경로를 사용한다.

```text
프로젝트 데이터
└─ 문서
   └─ /worlds/:worldId/projects/:projectId/documents
```

프로젝트 문서 관리에서는 다음 기능을 제공한다.

- 문서 생성
- 문서 조회
- 문서 수정
- 문서 삭제·복원
- 사용·미사용 전환
- 관계 조회·추가

## 15. 핵심 원칙

- `/docs`를 서비스의 기본 문서 탐색 화면으로 사용한다.
- `/`는 `/docs`로 리다이렉트한다.
- `/docs`에는 모든 월드·프로젝트의 문서를 표시한다.
- 문서별 월드와 프로젝트를 명확하게 노출한다.
- 프로젝트를 선택한 후 해당 프로젝트의 카테고리 트리를 표시한다.
- 문서 생성 권한이 있는 관리자에게만 새 문서 작성 버튼을 표시한다.
- 문서 관리는 프로젝트 대시보드와 프로젝트 레이아웃에서 처리한다.
- 문서 탐색과 문서 관리는 데이터 일부가 겹치더라도 목적과 레이아웃을 분리한다.
