# 인증 레이아웃 설계

## 1. 목적

인증 레이아웃은 로그인, 비밀번호 찾기·재설정, 최초 비밀번호 변경과 인증 오류를 처리하는 전용 레이아웃이다.

좌측 메뉴 없이 화면 정중앙에 인증 콘텐츠 영역을 배치한다.

## 2. 공통 구조

```text
전체 화면
└─ 중앙 인증 영역
   ├─ 옴니노드 로고
   ├─ 화면 제목
   ├─ 안내문
   ├─ 인증 폼
   └─ 보조 이동 링크
```

## 3. 화면과 콘텐츠 매핑

| 화면 | 경로 | 콘텐츠 |
|---|---|---|
| 로그인 | `/auth/sign-in` | 이메일, 비밀번호, 로그인 |
| 비밀번호 찾기 | `/auth/forgot-password` | 이메일 입력, 재설정 메일 요청 |
| 비밀번호 재설정 | `/auth/reset-password` | 재설정 토큰 확인, 새 비밀번호 입력 |
| 최초 비밀번호 변경 | `/auth/change-password` | 임시 비밀번호 확인, 새 비밀번호 설정 |
| 인증 오류 | `/auth/error` | 만료·위조·잘못된 인증 링크 안내 |

회원가입 화면은 제공하지 않는다. 관리자 계정은 승인 또는 초대를 통해서만 생성한다.

## 4. 로그인

```text
이메일
비밀번호
[로그인]

비밀번호를 잊으셨나요?
```

### 4.1 처리 흐름

1. 이메일과 비밀번호를 입력한다.
2. 계정 상태와 비밀번호를 확인한다.
3. 최초 비밀번호 변경 대상인지 확인한다.
4. 변경 대상이면 최초 비밀번호 변경 화면으로 이동한다.
5. 변경 완료 계정이면 역할과 접근 범위에 맞는 화면으로 이동한다.

### 4.2 로그인 이후 이동

| 조건 | 이동 |
|---|---|
| 슈퍼 어드민 | 옴니노드 대시보드 |
| 일반·서브 어드민 | 내 대시보드 |
| 최초 비밀번호 미변경 | 최초 비밀번호 변경 |
| 사용 중지 계정 | 로그인 차단 안내 |
| 삭제 계정 | 로그인 차단 안내 |

## 5. 비밀번호 찾기

```text
가입된 이메일
[비밀번호 재설정 메일 보내기]

로그인으로 돌아가기
```

보안상 이메일 존재 여부를 직접 노출하지 않고 동일한 결과 메시지를 보여준다.

> 입력한 이메일로 등록된 계정이 있다면 비밀번호 재설정 안내를 발송했습니다.

## 6. 비밀번호 재설정

이메일 링크를 통해 진입한다.

```text
새 비밀번호
새 비밀번호 확인
[비밀번호 재설정]
```

### 6.1 상태 처리

- 유효한 토큰: 비밀번호 변경 폼 노출
- 만료된 토큰: 재발급 안내
- 이미 사용한 토큰: 재발급 안내
- 잘못된 토큰: 인증 오류 안내
- 변경 완료: 로그인 화면 이동

## 7. 최초 비밀번호 변경

슈퍼 어드민을 제외한 관리자가 임시 비밀번호로 처음 로그인했을 때 강제로 이동한다.

```text
현재 임시 비밀번호
새 비밀번호
새 비밀번호 확인
[비밀번호 변경]
```

### 7.1 접근 제한

최초 비밀번호를 변경하기 전에는 다음 화면에 접근할 수 없다.

- 내 대시보드
- 월드 대시보드
- 프로젝트 대시보드
- 문서 화면
- 개인 정보 화면

비밀번호 변경과 로그아웃만 허용한다.

## 8. 인증 오류

| 오류 유형 | 표시 내용 |
|---|---|
| 토큰 만료 | 인증 링크가 만료됨 |
| 토큰 사용 완료 | 이미 사용된 인증 링크 |
| 잘못된 토큰 | 유효하지 않은 인증 요청 |
| 계정 비활성화 | 사용할 수 없는 계정 |
| 계정 삭제 | 삭제된 계정 |
| 접근 권한 없음 | 해당 인증 작업을 수행할 수 없음 |

오류 내용에 따라 로그인 또는 비밀번호 재설정 요청 화면으로 이동하는 버튼을 제공한다.

## 9. 제외하는 화면

- 회원가입
- 공개 관리자 신청
- 소셜 로그인
- 초대 수락

관리자 생성과 권한 부여는 대시보드에서 처리한다. 생성된 관리자는 이메일로 받은 임시 비밀번호를 사용해 로그인하며 별도의 초대 수락 절차는 두지 않는다.
