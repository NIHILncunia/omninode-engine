# 어드민 레이아웃 메뉴 설계

## 1. 목적

어드민 레이아웃은 슈퍼 어드민, 일반 어드민, 서브 어드민이 공통으로 사용하는 개인 업무 영역이다.

시스템 전체, 월드 또는 프로젝트 자체를 관리하는 대시보드와 달리 현재 로그인한 관리자를 기준으로 자신이 생성한 데이터와 관리 중인 데이터를 모아 보여준다. 개인 정보와 비밀번호 변경 기능도 이 영역에서 제공한다.

## 2. 기본 방향

어드민 페이지의 중심은 계정 설정이 아니라 **개인 업무 대시보드**로 한다.

- 역할에 관계없이 동일한 레이아웃을 사용한다.
- 관리자별 역할과 권한에 따라 노출되는 데이터 범위만 달라진다.
- 데이터 편집 화면을 중복 제공하지 않고 해당 월드·프로젝트 대시보드 또는 문서 화면으로 연결한다.
- 개인 정보와 보안 기능은 별도 메뉴 그룹으로 구분한다.
- 개인 업무 영역임을 명확히 하기 위해 기본 경로는 `/my`를 사용한다.

## 3. 좌측 메뉴

```text
내 업무
├─ 내 대시보드
├─ 내가 생성한 데이터
└─ 관리 중인 데이터

계정
├─ 내 정보
└─ 비밀번호 변경
```

## 4. 메뉴와 콘텐츠 매핑

| 메뉴 그룹 | 좌측 메뉴 | 경로 | 메인 콘텐츠 |
|---|---|---|---|
| 내 업무 | 내 대시보드 | `/my` | 관리 범위 요약, 관리 중인 월드·프로젝트, 최근 생성 데이터, 최근 수정 데이터 |
| 내 업무 | 내가 생성한 데이터 | `/my/created` | 자신이 생성한 월드·프로젝트·카테고리·템플릿·관계·문서 통합 목록 |
| 내 업무 | 관리 중인 데이터 | `/my/managed` | 자신에게 관리 권한이 있는 월드·프로젝트와 세부 권한 범위 |
| 계정 | 내 정보 | `/my/profile` | 이름과 이메일 등 개인 정보 조회·수정 |
| 계정 | 비밀번호 변경 | `/my/password` | 현재 비밀번호 확인 후 새 비밀번호 설정 |

## 5. 내 대시보드

### 5.1 관리자 정보

현재 로그인한 관리자의 기본 정보를 표시한다.

| 항목 | 내용 |
|---|---|
| 이름 | 관리자 이름 |
| 이메일 | 관리자 이메일 |
| 역할 | 슈퍼 어드민, 일반 어드민 또는 서브 어드민 |

### 5.2 관리 범위 요약

| 항목 | 내용 |
|---|---|
| 관리 월드 | 관리 가능한 월드 수 |
| 관리 프로젝트 | 관리 가능한 프로젝트 수 |
| 생성 데이터 | 자신이 생성한 전체 데이터 수 |
| 관리 문서 | 접근하거나 관리할 수 있는 문서 수 |

### 5.3 관리 중인 범위

관리 중인 월드와 프로젝트를 보여주고 해당 대시보드로 이동할 수 있게 한다.

```text
관리 중인 월드
└─ 월드별 접근 가능한 프로젝트

관리 중인 프로젝트
└─ 프로젝트별 보유 권한
```

### 5.4 최근 작업

- 최근 생성한 데이터
- 최근 수정한 데이터

최근 접근한 문서는 접근 기록을 저장하는 DB와 API가 존재할 때만 추가한다.

## 6. 내가 생성한 데이터

자신이 생성한 데이터를 종류별로 전환하여 조회한다.

```text
[전체] [월드] [프로젝트] [카테고리] [템플릿] [관계] [문서]
```

| 목록 항목 | 내용 |
|---|---|
| 데이터 종류 | 월드, 프로젝트, 카테고리, 템플릿, 관계 또는 문서 |
| 이름 | 데이터 이름 또는 문서 제목 |
| 소속 | 데이터가 속한 월드와 프로젝트 |
| 상태 | 사용, 미사용 또는 삭제 |
| 생성일 | 자신이 데이터를 생성한 날짜 |
| 수정일 | 데이터를 마지막으로 수정한 날짜 |
| 바로가기 | 실제 관리 화면으로 이동 |

생성 여부는 공통 생성자 컬럼을 기준으로 판별한다.

## 7. 관리 중인 데이터

개별 문서를 모두 나열하지 않고 자신에게 관리 권한이 부여된 상위 범위를 중심으로 보여준다.

| 표시 단위 | 내용 |
|---|---|
| 월드 | 월드 이름, 관리자 역할, 접근 가능한 프로젝트 수 |
| 프로젝트 | 프로젝트 이름, 소속 월드, 부여된 권한 |
| 권한 | 카테고리·템플릿·관계·문서 등에 대한 생성·수정·삭제 권한 |
| 이동 | 월드 또는 프로젝트 대시보드로 이동 |

- 서브 어드민은 실제로 부여받은 관리 범위만 볼 수 있다.
- 일반 어드민과 슈퍼 어드민도 동일한 UI를 사용한다.
- 역할과 권한에 따라 조회 결과만 달라진다.

## 8. 내 정보

| 항목 | 처리 |
|---|---|
| 이름 | 변경 가능 |
| 이메일 | 변경 정책 확정 필요 |
| 역할 | 조회만 가능 |
| 계정 상태 | 조회만 가능 |
| 가입일 | 조회만 가능 |
| 마지막 로그인 | 관련 데이터가 존재하는 경우 조회만 가능 |

역할과 관리 권한은 개인이 직접 변경하지 않는다. 상위 관리자가 별도의 관리자 관리 화면에서 변경한다.

## 9. 비밀번호 변경

로그인한 관리자가 자신의 비밀번호를 변경한다.

```text
현재 비밀번호
새 비밀번호
새 비밀번호 확인
```

비밀번호를 잊은 사용자가 이메일 인증을 거쳐 진행하는 비밀번호 재설정은 인증 레이아웃에서 처리한다.

## 10. 미결 사항

- 관리자 이메일을 직접 변경할 수 있는지에 대한 정책
- 최근 접근 문서를 지원하기 위한 접근 기록 저장 여부
- 월드와 프로젝트의 최종 소유·매핑 관계에 따른 소속 정보 표현 방식
